# Python Web & APIs

## Choosing the framework

| Need | Pick |
| --- | --- |
| API-first, async, typed | **FastAPI** (pydantic validation, OpenAPI auto-docs, `async def` routes) |
| Full-stack, admin, ORM heavy | **Django** (batteries included, Django REST framework for APIs) |
| Small service, full control | **Flask** or stdlib `http.server` |
| Background jobs | **Celery** (Redis/RabbitMQ) or **arq** (async) or Django Q |

## FastAPI essentials

```python
from fastapi import FastAPI, Depends, HTTPException
from pydantic import BaseModel

app = FastAPI()


class CreateUser(BaseModel):
    name: str
    email: str  # pydantic validates (EmailStr with email-validator)


@app.post("/users", status_code=201)
async def create_user(
    body: CreateUser, db: Session = Depends(get_db)
): ...  # body is validated before the handler runs
```

- Dependency injection via `Depends` — DB session, current user, settings.
- Auth: `HTTPBearer` / OAuth2PasswordBearer + JWT (`python-jose` or `PyJWT`); check **object-level** permissions per route.
- Run: `uvicorn app.main:app --reload` (dev), gunicorn with uvicorn workers in prod.

## Database

- **SQLAlchemy 2.x** style: `select()` statements, async via `AsyncSession` + `asyncpg` (Postgres) / `aiosqlite`.
- Raw async drivers when you want no ORM: `asyncpg` (Postgres), `aiomysql`.
- Connection pooling configured on the engine; `async with session.begin()` for transactions.

## Migrations: Alembic

- `alembic init alembic`, `alembic revision --autogenerate -m "..."`, `alembic upgrade head`.
- Review autogenerated migrations before applying — autogenerate misses renames (looks like drop+add).
- Expand/contract: nullable column first, backfill, then constraint — never destructive with the new code.

## GraphQL: Strawberry

```python
import strawberry


@strawberry.type
class Query:
    @strawberry.field
    async def user(self, id: int) -> User | None: ...
```

- Schema-first, typed resolvers, DataLoader for N+1 (`strawberry.dataloader`).
- For full GraphQL depth — schema design, typed errors, depth limits, testing — load `python-graphql`.

## API hygiene

- Version the API (`/v1/...`); return consistent error shapes (FastAPI: `HTTPException` + custom handler → `{"detail": ...}`).
- Rate limiting (`slowapi`), body size limits, timeouts on outbound calls (`httpx` with `timeout=`).
- OpenAPI docs in prod only if intended; disable `/docs` publicly if sensitive.
